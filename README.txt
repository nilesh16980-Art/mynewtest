QUICK TEST WEBSITE PACKAGE

Files:
- index.html   Main website
- style.css    Website design
- script.js    Questions, answers and scoring
- assets/      Put your own images here

CUSTOMIZE:
1. Open script.js and replace the questions.
2. Change the WhatsApp number in index.html.
   Current demo number: 919999999999
   Format: country code + number, without + or spaces.
3. To add a hero image, place your image in assets/ and add a CSS background-image or <img> in index.html.

HOSTING:
This is a static HTML/CSS/JS package. It can be hosted on services such as Cloudflare Pages, Netlify or GitHub Pages. Check the provider's current terms and limits before commercial use.

IMPORTANT:
The WhatsApp button opens WhatsApp with a pre-filled query. It does not require a backend.
